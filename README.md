# TBT Results

One results page for The Blue Tree: every test, deck, game, drill and homework a student finishes, for teachers (Teacher Tools) and for the student (Learning Tools).

Reads the shared activity log kept by TBT Notes (`{prefix}tbt_activity`, Notes 1.22.0+). TBT Points will be built on the same rows later.

- `docs/prototypes/results.html` — the approved prototype (teacher and student views; tablet and desktop only; no page header, Divi supplies it).

No plugin code yet.
